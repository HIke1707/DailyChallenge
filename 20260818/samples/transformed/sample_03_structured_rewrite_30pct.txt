# 企業級 API v2.4 身分認證與安全遷移規範

為強化企業資安防護基線，全系統將於 2026 年 Q4 前由傳統 Cookie-Session 全面轉移至 OAuth 2.1 與 OIDC 規範。

### 關鍵架構升級摘要
- **標準化 JWT Token**：強制採用 RFC 9068 格式，全面禁用靜態 API Key 與非對稱憑證不全之 Basic 驗證。
- **自動化公鑰輪替**：各服務透過標準 JWKS 端點每 72 小時自動獲取最新驗證公鑰。
- **細粒度授權**：捨棄舊有單一 Role 判定，一律依最小權限原則以 Scope 與 Claims 進行存取控制。

### 權杖時效與安全防護
- **短期 Access Token**：存活時間最長 15 分鐘，僅支援 RS256/ES256/EdDSA 等非對稱演算法。
- **單次 Refresh Token 輪替**：任何重複使用已作廢 Token 的異常行為，將立即觸發該使用者所有使用中會話的強制中斷。

### 上線前查核項目
- API Gateway 必須建立 JWKS 本地快取以抵抗認證中心斷線風險。
- 所有日誌管線必須設置 PII 與 Authorization 標頭即時遮蔽過濾器。
- 每一筆外部請求皆須附加 `X-Correlation-ID` 以利分散式日誌鏈路追蹤。
