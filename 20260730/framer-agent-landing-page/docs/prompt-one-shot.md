## 版面與響應式規格

- 全站內容容器最大寬度為 1200px，Desktop 左右 padding 32px，Mobile 左右 padding 16px。
- 每個 Section Desktop 上下間距 96px，Mobile 為 64px。
- Hero 在 960px 以上採雙欄；小於 960px 改為單欄，文字在上、視覺內容在下。
- 挑戰流程卡片：
  - Desktop：3 欄 Grid。
  - Tablet：2 欄 Grid。
  - Mobile：1 欄，卡片滿寬。
- 任務圖片統一使用 16:9 比例、圓角 16px，圖片不可拉伸變形。
- 已完成挑戰卡片：
  - Desktop：3 欄。
  - Mobile：單欄。
  - 每張卡片的三張圖片使用左右箭頭與圓點切換。
  - 不要自動播放或旋轉，避免使用者無法閱讀。
- 教練評分折線圖：
  - X 軸為完成日期，Y 軸為分數。
  - 只使用提供的真實分數。
  - 若沒有足夠資料，改顯示「尚無足夠評分資料」空狀態。

## 手機版規格（寬度小於 768px）

- 所有 Section、Stack、卡片與圖片容器的寬度均設定為 **Fill**；不要使用大於螢幕寬度的固定 px 寬度，也不要設定會造成橫向捲動的最小寬度。
- 頁面實際可用寬度為 `100vw - 32px`（左右各 16px）；任何元件都不可超出此範圍。長標題與任務類型必須自動換行，不可被截斷或撐開版面。
- Hero 改為單欄：標題、介紹文字、CTA、視覺內容依序由上而下；文字靠左，不使用左右並排。
- Hero 標題使用 40px／1.1 行高以下；Section 標題使用 28px／1.2 行高以下；本文至少 16px／1.6 行高，確保閱讀性。
- 兩個 Hero CTA 在手機版改為垂直堆疊、滿寬，按鈕高度至少 48px，按鈕間距 12px；不可並排而使文字擠壓。
- 挑戰流程與已完成挑戰都改為單欄卡片；卡片寬度 Fill、內距 20px、卡片間距 16px。任務類型標籤可換行，不能超出卡片。
- 圖片保持 16:9，使用 `cover` 顯示且不可變形；卡片圖片與輪播容器需設定 overflow hidden、圓角 16px。
- 已完成挑戰的圖片輪播只顯示一張圖片；左右按鈕需放在圖片內側且至少 44 × 44px，圓點可點擊，且不自動播放。若沒有圖片，不顯示空白輪播區，改顯示「待補圖片」。
- 教練評分圖表在手機版滿寬顯示；日期可簡化為 `MM/DD`，標籤數量可減少，但資料點與分數不可刪除或捏造。圖表本身不得要求使用者橫向捲動。
- 頁尾 CTA 在手機版垂直排列；所有互動元件需保留清楚的 hover、focus 與 tap 回饋。

## 資料與內容規則

- 僅使用我提供或上傳至 Framer Assets 的圖片、文字與連結。
- 不可杜撰任務名稱、日期、分數、成果、IG 帳號、GitHub 連結或人物圖片。
- 若某張卡片資料不足，顯示「待補資料」，不要生成假內容。
- 主要 CTA 與次要 CTA 必須使用我提供的 IG 連結；GitHub CTA 必須使用我提供的 GitHub 連結。
- CTA 按鈕要有 hover 與 keyboard focus 狀態。

## 驗收條件

- Desktop 寬度 1440px 時內容不超過 1200px。
- Mobile 寬度 390px 時不可出現水平捲動。
- 所有文字在 Mobile 都可閱讀，按鈕最小高度 44px。
- 於 390px 與 375px 寬度各檢查一次：Hero、任務卡、完成挑戰輪播與評分圖表均不可裁切、重疊或超出畫面。
- 所有圖片有替代文字。
- 不可使用未授權外部圖片、假資料或未提供的外部連結。
